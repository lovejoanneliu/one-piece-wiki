# 🧠 One Piece & LLM Research Wiki

本專案結合 **Andrej Karpathy 的 LLM Wiki 模式**、**Fandom 多維度知識圖譜架構** 與 **GitHub Pages 靜態展示網頁**，透過 `AGENTS.md` / `CLAUDE.md` 規範讓 AI Coding Agent 自動維護論文精讀、研究筆記與互動式 HTML 簡報。

## 🌐 公開網站網址
啟用 GitHub Pages 後，即可透過以下網址公開瀏覽：
`https://lovejoanneliu.github.io/one-piece-wiki/`

## 📂 專案結構
- `index.html`：GitHub Pages 公開入口網頁（整合 Wiki 知識圖譜檢索、LaTeX 公式渲染與簡報瀏覽）
- `AGENTS.md` / `CLAUDE.md`：AI Agent 行為規範與四大工作流定義
- `raw/`：唯讀原始文獻庫（論文、文章）
- `wiki/`：結構化知識庫（`architectures/`、`methods/`、`papers/`、`syntheses/`）
- `notes/`：嚴格基於 Wiki 撰寫的研究筆記
- `slide_outlines/`：簡報逐頁腳本大綱
- `presentations/`：獨立單檔 HTML 簡報
